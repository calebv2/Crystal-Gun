# Crystal Gun

A rechargeable crystal pistol for the PC version of **A Township Tale**. Hold the trigger to charge a shot for one second. Each shot has a 2.5-second cooldown.

## Install

1. Install MelonLoader and [SyncLib](https://github.com/MrDuckTheFifth/SyncLib) on the dedicated server and on each player's client.
2. Download the matching DLLs from the [latest release](https://github.com/calebv2/Crystal-Gun/releases/latest). Stop the server and close the game before replacing an older pistol DLL.
3. Put `SciFiPistol.Server.dll` in the dedicated server's `Mods` folder. Put `SciFiPistol.Client.dll` in each player's `Mods` folder. Install only the DLL for that role, then restart.

## Find and reload the pistol

On displayed cave layer **100 and deeper**, each eligible loot selection has a **0.05% chance** (1 in 2,000) to produce a pistol. This is a chance per eligible loot slot, not per floor.

To reload an empty pistol, hold a crystal gem (item #8002) in your other hand and bring it to the chamber. Hold it there briefly until absorption begins. One gem supplies four shots; the pistol can fire again after the three-second reload.
